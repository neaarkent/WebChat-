== Description ==

Facebook Messenger Customer Chat is a simple and lightweight WordPress plugin that adds Facebook Messenger chat functionality to your website. This allows your customers to contact you directly through Facebook Messenger, making it easier to provide support and engage with your audience.

= Features =

* Easy integration with Facebook Messenger
* Help customers contact your business instantly
* Get notifications immediately when customers message you
* Support for 100+ languages
* Simple on/off toggle
* Lightweight and fast
* No coding required
* Works with any WordPress theme
* Mobile responsive

= Benefits =

* **Improve Customer Support** - Let customers reach you instantly through Messenger
* **Increase Engagement** - Make it easy for visitors to ask questions
* **Never Miss a Message** - Get notifications on your phone and desktop
* **Build Relationships** - Continue conversations even after customers leave your site
* **Grow Your Business** - Better communication leads to more sales

== Installation ==

= Automatic Installation =

1. Log in to your WordPress admin panel
2. Go to Plugins > Add New
3. Search for "Facebook Messenger Customer Chat"
4. Click "Install Now" and then "Activate"

= Manual Installation =

1. Download the plugin zip file
2. Log in to your WordPress admin panel
3. Go to Plugins > Add New > Upload Plugin
4. Choose the downloaded zip file and click "Install Now"
5. Activate the plugin

= Configuration =

1. Go to Messenger Chat > Settings in your WordPress admin
2. Get your Facebook Page ID from your Facebook Page (Settings > About > Page ID)
3. Add your website domain to Facebook whitelist (Page Settings > Messenger Platform > Whitelisted Domains)
4. Enter your Page ID in the plugin settings
5. Select your preferred language
6. Enable the chat widget
7. Click "Save Changes"

That's it! Visit your website to see the Messenger chat widget.

== Frequently Asked Questions ==

= Do I need a Facebook Page? =

Yes, you need a Facebook Page (not a personal profile) to use this plugin.

= How do I find my Facebook Page ID? =

Go to your Facebook Page > Settings > About > Page ID. The Page ID is a numeric value.

= Why isn't the chat widget showing on my site? =

Make sure:
* The plugin is activated
* The chat widget is enabled in settings
* You've entered a valid Facebook Page ID
* Your domain is whitelisted in your Facebook Page settings (Settings > Messenger Platform > Whitelisted Domains)

= Can I customize the chat widget appearance? =

The chat widget appearance is controlled by Facebook. You can change the language through the plugin settings.

= Does this work with WooCommerce? =

Yes, this plugin works with WooCommerce and any other WordPress plugins.

= Is this plugin free? =

Yes, this plugin is completely free to use.

= Will this slow down my website? =

No, the plugin is lightweight and loads Facebook's script asynchronously, so it won't affect your page load speed.
